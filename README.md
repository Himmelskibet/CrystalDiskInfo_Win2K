# CrystalDiskInfo_Win2K
CrystalDiskInfo patched to support Windows 2000.

This is downloaded from the original page that hosts CrystalDiskInfo at https://crystalmark.info/en/software/crystaldiskinfo/  , and is patched using CFF Explorer to work on stock Windows 2000 with SP4.
Older service packs of Windows 2000 are untested (for now).

Special thanks to EAZY BLACK over on Discord for making wrappers for Windows 2000, which is what makes this possible.
